### Q1. BITSAT 2024 (Memory Based Paper 1)

*Type:* `singleCorrect` | *Level:* `1`

Number of subsets of set of letter of word 'MONOTONE'.

**Options:**

- **(A)** $8$
- **(B)** $256$
- **(C)** $64$
- **(D)** $32$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $32$**

**Detailed Solution:**

Set created out of alphabet of word 'MONO- TONE' is $\{\mathrm{M}, \mathrm{N}, \mathrm{O}, \mathrm{T}, \mathrm{E}\}$
$\therefore$ Total number of subsets $=2^5=32$

</details>

### Q2. BITSAT 2023 (Memory Based Paper 2)

*Type:* `singleCorrect` | *Level:* `1`

If $n(\mathrm{~A})=1000, n(\mathrm{~B})=500$ and if $n(\mathrm{~A} \cap \mathrm{B}) \geq 1$ and $n(\mathrm{~A} \cup \mathrm{B})=p$, then

**Options:**

- **(A)** $500 \leq p \leq 1000$
- **(B)** $1001 \leq p \leq 1498$
- **(C)** $1000 \leq p \leq 1498$
- **(D)** $1000 \leq p \leq 1499$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $1000 \leq p \leq 1499$**

**Detailed Solution:**

$\mathrm{n}(\mathrm{A})=1000, \mathrm{n}(\mathrm{B})=500, \mathrm{n}(\mathrm{A} \cap \mathrm{B}) \geq 1$, $n(A \cup B)=p ; n(A \cup B)=n(A)+n(B)-n(A \cap B)$ $\mathrm{p}=1000+500-\mathrm{n}(\mathrm{A} \cap \mathrm{B}) \Rightarrow 1 \leq \mathrm{n}(\mathrm{A} \cap \mathrm{B}) \leq 500$
Hence $p \leq 1499$ and $p \geq 1000 \Rightarrow 1000 \leq p \leq 1499$

</details>

### Q3. BITSAT 2016

*Type:* `singleCorrect` | *Level:* `1`

Two finite sets have $m$ and $n$ elements. The number of subsets of the first set is 112 more than that of the second set. The values of $m$ and $n$ respectively are,

**Options:**

- **(A)** 4,7
- **(B)** 7,4
- **(C)** 4,4
- **(D)** 7,7

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) 7,4**

**Detailed Solution:**

$2^{m}-2^{n}=112 \Rightarrow 2^{n}\left(2^{m-n}-1\right)=16.7$

$\quad \therefore \quad 2^{n}\left(2^{m-n}-1\right)=2^{4}\left(2^{3}-1\right)$

Comparing we get $n=4$ and $m-n=3$ $\Rightarrow n=4$ and $m=7$

</details>

### Q4. BITSAT 2010

*Type:* `singleCorrect` | *Level:* `2`

Let \(\mathrm{A}=\{x: x \in \mathrm{R},|x|  < 1\}\);
\(\mathrm{B}=\{x: x \in \mathrm{R},|x-1| \geq 1\} \text { and } \mathrm{A} \cup \mathrm{B}=\mathrm{R}-\mathrm{D} \text {, }\)
then the set \(\mathrm{D}\) is

**Options:**

- **(A)** \(\{x: 1  < x \leq 2\}\)
- **(B)** \(\{x: 1 \leq x  < 2\}\)
- **(C)** \(\{x: 1 \leq x \leq 2\}\)
- **(D)** None of these

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) \(\{x: 1 \leq x  < 2\}\)**

**Detailed Solution:**

\(\begin{aligned}
& \mathrm{A}=[x: x \in \mathrm{R},-1  < x < 1] \\
& \mathrm{B}=[x: x \in \mathrm{R}: x-1 \leq-1 \text { or } x-1 \geq 1] \\
&=[x: x \in R: x \leq 0 \text { or } x \geq 2] \\
& \therefore A \cup B=R-D,
\end{aligned}\)
where \(D=[x: x \in R, 1 \leq x < 2]\)

</details>

### Q5. BITSAT 2009

*Type:* `singleCorrect` | *Level:* `1`

If \(A=\{1,2,3,4,5\}\), then the number of proper subsets of \(A\) is

**Options:**

- **(A)** 31
- **(B)** 38
- **(C)** 48
- **(D)** 54

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) 31**

**Detailed Solution:**

Number of proper subsets of \(A=2^n-1\) Given: \(A=\{1,2,3,4,5\}\)
Here \(n=5\)
\(\therefore\) no. of proper subsets \(=2^5-1\)

</details>
