### Q1. BITSAT 2013

*Type:* `singleCorrect` | *Level:* `2`

The value of

$\cos \left[\frac{1}{2} \cos ^{-1}\left(\cos \left(\sin ^{-1} \frac{\sqrt{63}}{8}\right)\right)\right]$ is $-$

**Options:**

- **(A)** $3 / 16$
- **(B)** $3 / 8$
- **(C)** $3 / 4$
- **(D)** $3 / 2$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $3 / 4$**

**Detailed Solution:**

The given trigonometric ratio

$$

\begin{array}{l}

=\cos \left[\frac{1}{2}\left(\cos \left(\cos ^{-1} \frac{1}{8}\right)\right)\right] \\

=\cos \left(\frac{1}{2} \cos ^{-1} \frac{1}{8}\right) \\

=\sqrt{\frac{1+\cos \left(\cos ^{-1} \frac{1}{8}\right)}{2}}=\frac{3}{4}

\end{array}

$$

</details>

### Q2. BITSAT 2012

*Type:* `singleCorrect` | *Level:* `3`

If $k \leq \sin ^{-1} x+\cos ^{-1} x+\tan ^{-1} x \leq K,$ then $-$

**Options:**

- **(A)** $\mathrm{k}=0, \mathrm{~K}=\pi$
- **(B)** $\mathrm{k}=0, \mathrm{~K}=\pi / 2$
- **(C)** $\mathrm{k}=\pi / 2, \mathrm{~K}=\pi$
- **(D)** None of these

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) None of these**

**Detailed Solution:**

$\sin ^{-1} x+\cos ^{-1} x+\tan ^{-1} x=\frac{\pi}{2}+\tan ^{-1} x$
Since domain of the function $\mathrm{x} \in[-1,1]$ $\therefore-\frac{\pi}{4} \leq \tan ^{-1} x \leq \frac{\pi}{4}$
Hence, $\mathrm{k}=\frac{\pi}{4}$ and $\mathrm{K}=\frac{3 \pi}{4}$

</details>
