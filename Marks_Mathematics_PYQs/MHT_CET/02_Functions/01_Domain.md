The domain of the function $f(x) = \dfrac{1}{\sqrt{|x| - x}}$ is

**Options:**

- **(A)** $(0, \infty)$
- **(B)** $(-\infty, 0)$
- **(C)** $(-\infty, \infty) - \{0\}$
- **(D)** $(-\infty, \infty)$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $(-\infty, 0)$**

**Detailed Solution:**

The domain of the function is $(-\infty, 0)$.
