### Q1. MHT CET 2025 (22 Apr Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

The p.d.f. of a continuous random variable X is
$\mathrm{f}(x)=\left\{\begin{array}{cc}
\frac{x^2}{18} & \text { if }-3 < x < 3 \\
0 & \text { otherwise }
\end{array}\right.$
Then $\mathrm{P}[|\mathrm{X}| < 2]=$

**Options:**

- **(A)** $\frac{1}{27}$
- **(B)** $\frac{2}{13}$
- **(C)** $\frac{8}{27}$
- **(D)** $\frac{4}{27}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $\frac{8}{27}$**

**Detailed Solution:**

The probability $\mathrm{P}[|\mathrm{X}| < 2]$ is equivalent to $\mathrm{P}[-2 < \mathrm{X} < 2]$.

$\mathrm{P}[-2 < \mathrm{X} < 2] = \int_{-2}^{2} \mathrm{f}(x) \mathrm{d}x$

Since the interval $(-2, 2)$ lies within $(-3, 3)$, we substitute $\mathrm{f}(x) = \dfrac{x^2}{18}$:

$\mathrm{P}[-2 < \mathrm{X} < 2] = \int_{-2}^{2} \dfrac{x^2}{18} \mathrm{d}x$

Evaluating the integral:

$\int_{-2}^{2} \dfrac{x^2}{18} \mathrm{d}x = \left[ \dfrac{x^3}{54} \right]_{-2}^{2}$

$= \dfrac{2^3}{54} - \dfrac{(-2)^3}{54}$

$= \dfrac{8}{54} - \left( -\dfrac{8}{54} \right)$

$= \dfrac{16}{54}$

$= \dfrac{8}{27}$

Answer: $\frac{8}{27}$

</details>
