### Q1. MHT CET 2025 (23 Apr Shift 1)

*Type:* `singleCorrect` | *Level:* `3`

If $x=-2+\sqrt{-3}$, then the value of $2 x^4+5 x^3+7 x^2-x+38$ is equal to

**Options:**

- **(A)** $1$
- **(B)** $-2$
- **(C)** $3$
- **(D)** $5$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $3$**

**Detailed Solution:**

Given $x = -2 + \sqrt{-3}$

$x + 2 = \sqrt{-3}$

Squaring both sides, we get:

$(x + 2)^2 = -3$

$x^2 + 4x + 4 = -3$

$x^2 + 4x + 7 = 0$

Now, we divide the given polynomial $2x^4 + 5x^3 + 7x^2 - x + 38$ by $x^2 + 4x + 7$:

$2x^4 + 5x^3 + 7x^2 - x + 38 = 2x^2(x^2 + 4x + 7) - 3x^3 - 7x^2 - x + 38$

$= 2x^2(x^2 + 4x + 7) - 3x(x^2 + 4x + 7) + 5x^2 + 20x + 38$

$= 2x^2(x^2 + 4x + 7) - 3x(x^2 + 4x + 7) + 5(x^2 + 4x + 7) + 3$

$= (2x^2 - 3x + 5)(x^2 + 4x + 7) + 3$

Substituting $x^2 + 4x + 7 = 0$ into the expression:

$= (2x^2 - 3x + 5)(0) + 3 = 3$

Answer: $3$

</details>

### Q2. MHT CET 2023 (14 May Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

The equation $x^3+x-1=0$ has

**Options:**

- **(A)** no real root.
- **(B)** exactly two real roots.
- **(C)** exactly one real root.
- **(D)** more than two real roots.

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) exactly one real root.**

**Detailed Solution:**

Let $\mathrm{f}(x)=x^3+x-1$
A root of $\mathrm{f}(x)$ exists, if $\mathrm{f}(x)=0$ for at least one value of $x$.
$$
\begin{aligned}
& \mathrm{f}(0)=-1 < 0 \\
& \mathrm{f}(1)=1>0
\end{aligned}
$$
$\therefore \quad$ By intermediate value theorem, there has to be a point ' $c$ ' between 0 and 1 such that $\mathrm{f}(x)=0$.
$\therefore \quad$ The given equation has exactly one real root.
Alternate Method:
Let $\mathrm{f}(x)=x^3+x-1$
$$
\begin{array}{ll}
\therefore \quad \mathrm{f}^{\prime}(x)=3 x^2+1 \\
\quad \Rightarrow \mathrm{f}^{\prime}(x)>0 \quad \forall x \in \mathrm{R}
\end{array}
$$
$\Rightarrow \mathrm{f}(x)$ is an increasing function.
$\Rightarrow \mathrm{f}(x)$ intersects $\mathrm{X}$-axis at only one point.
$\therefore \quad$ The given equation has exactly one real root.

</details>
