### Q1. MHT CET 2025 (25 Apr Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

The maximum value of the function $a \sin x+\mathrm{b} \cos x$ is

**Options:**

- **(A)** $\sqrt{a^2+b^2}$
- **(B)** $\sqrt{a^2-b^2}$
- **(C)** $a^2+b^2$
- **(D)** $a^2-b^2$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $\sqrt{a^2+b^2}$**

**Detailed Solution:**

Let $f(x) = a \sin x + b \cos x$

Multiply and divide by $\sqrt{a^2+b^2}$:

$f(x) = \sqrt{a^2+b^2} \left( \dfrac{a}{\sqrt{a^2+b^2}} \sin x + \dfrac{b}{\sqrt{a^2+b^2}} \cos x \right)$

Let $\cos \alpha = \dfrac{a}{\sqrt{a^2+b^2}}$ and $\sin \alpha = \dfrac{b}{\sqrt{a^2+b^2}}$

$f(x) = \sqrt{a^2+b^2} (\sin x \cos \alpha + \cos x \sin \alpha)$

$f(x) = \sqrt{a^2+b^2} \sin(x + \alpha)$

Since the maximum value of $\sin(x + \alpha)$ is $1$, the maximum value of $f(x)$ is $\sqrt{a^2+b^2}$.

Answer: $\sqrt{a^2+b^2}$

</details>

### Q2. MHT CET 2020 (12 Oct Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

$\quad$ The maximum value of the function $y=e^{5+\sqrt{3} \sin x+\cos x}$ is

**Options:**

- **(A)** $e^{7}$
- **(B)** $e^{2}$
- **(C)** $e^{5}$
- **(D)** $e^{8}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $e^{7}$**

**Detailed Solution:**

Maximum value of $\sqrt{3} \sin x+\cos x$ is $\sqrt{(\sqrt{3})^{2}+(1)^{2}}=2$ 
Hence maximum value of given function is $\mathrm{e}^{5+2}=\mathrm{e}^{7}$

</details>
