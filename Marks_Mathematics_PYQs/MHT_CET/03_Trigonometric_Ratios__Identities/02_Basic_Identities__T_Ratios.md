### Q1. MHT CET 2026 (20 May Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

If $\sec 2\theta = p + \tan 2\theta$ then, the value of $\cos^2\theta$ is

**Options:**

- **(A)** $\dfrac{(p-1)^2}{2(p^2+1)}$
- **(B)** $\dfrac{(p+1)^2}{2(p^2+1)}$
- **(C)** $\dfrac{p^2+1}{2(p+1)^2}$
- **(D)** $\dfrac{p^2+1}{2(p-1)^2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\dfrac{(p+1)^2}{2(p^2+1)}$**

**Detailed Solution:**

Given $\sec 2\theta - \tan 2\theta = p$

We know the identity $\sec^2 2\theta - \tan^2 2\theta = 1$

$\Rightarrow (\sec 2\theta - \tan 2\theta)(\sec 2\theta + \tan 2\theta) = 1$

$\Rightarrow p(\sec 2\theta + \tan 2\theta) = 1$

$\Rightarrow \sec 2\theta + \tan 2\theta = \dfrac{1}{p}$

Adding the two equations, we get:

$2\sec 2\theta = p + \dfrac{1}{p} = \dfrac{p^2+1}{p}$

$\Rightarrow \sec 2\theta = \dfrac{p^2+1}{2p}$

$\Rightarrow \cos 2\theta = \dfrac{2p}{p^2+1}$

Using the identity $\cos 2\theta = 2\cos^2\theta - 1$:

$2\cos^2\theta - 1 = \dfrac{2p}{p^2+1}$

$2\cos^2\theta = 1 + \dfrac{2p}{p^2+1} = \dfrac{p^2+1+2p}{p^2+1} = \dfrac{(p+1)^2}{p^2+1}$

$\Rightarrow \cos^2\theta = \dfrac{(p+1)^2}{2(p^2+1)}$

Answer: $\dfrac{(p+1)^2}{2(p^2+1)}$

</details>

### Q2. MHT CET 2026 (13 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

The value of expression $\tan 9^\circ - \tan 27^\circ - \tan 63^\circ + \tan 81^\circ$ is....

**Options:**

- **(A)** $1$
- **(B)** $2$
- **(C)** $4$
- **(D)** $8$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $4$**

**Detailed Solution:**

The given expression is $\tan 9^\circ - \tan 27^\circ - \tan 63^\circ + \tan 81^\circ$

Grouping the terms, we get:

$(\tan 9^\circ + \tan 81^\circ) - (\tan 27^\circ + \tan 63^\circ)$

Using $\tan(90^\circ - \theta) = \cot \theta$, this becomes:

$(\tan 9^\circ + \cot 9^\circ) - (\tan 27^\circ + \cot 27^\circ)$

Using the identity $\tan \theta + \cot \theta = \dfrac{\sin \theta}{\cos \theta} + \dfrac{\cos \theta}{\sin \theta} = \dfrac{1}{\sin \theta \cos \theta} = \dfrac{2}{\sin 2\theta}$:

$= \dfrac{2}{\sin 18^\circ} - \dfrac{2}{\sin 54^\circ}$

$= 2 \left( \dfrac{\sin 54^\circ - \sin 18^\circ}{\sin 18^\circ \sin 54^\circ} \right)$

Using the formula $\sin C - \sin D = 2 \cos \left(\dfrac{C+D}{2}\right) \sin \left(\dfrac{C-D}{2}\right)$:

$= 2 \left( \dfrac{2 \cos 36^\circ \sin 18^\circ}{\sin 18^\circ \sin 54^\circ} \right)$

Since $\sin 54^\circ = \sin(90^\circ - 36^\circ) = \cos 36^\circ$, the expression simplifies to:

$= 2 \left( \dfrac{2 \cos 36^\circ \sin 18^\circ}{\sin 18^\circ \cos 36^\circ} \right) = 4$

Answer: $4$

</details>

### Q3. MHT CET 2026 (12 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

If $\sin^4 \theta + \cos^4 \theta = \dfrac{5}{8}, 0 < \theta < \dfrac{\pi}{2}$, then $\sin 2\theta = ...$

**Options:**

- **(A)** $\dfrac{1}{2}$
- **(B)** $\dfrac{\sqrt{3}}{2}$
- **(C)** $\dfrac{1}{\sqrt{2}}$
- **(D)** $\dfrac{3}{4}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\dfrac{\sqrt{3}}{2}$**

**Detailed Solution:**

Given $\sin^4 \theta + \cos^4 \theta = \dfrac{5}{8}$

We know that $\sin^4 \theta + \cos^4 \theta = (\sin^2 \theta + \cos^2 \theta)^2 - 2\sin^2 \theta \cos^2 \theta$

$\Rightarrow 1 - 2\sin^2 \theta \cos^2 \theta = \dfrac{5}{8}$

$\Rightarrow 2\sin^2 \theta \cos^2 \theta = 1 - \dfrac{5}{8} = \dfrac{3}{8}$

Multiplying both sides by $2$, we get:

$4\sin^2 \theta \cos^2 \theta = \dfrac{3}{4}$

$\Rightarrow (2\sin \theta \cos \theta)^2 = \dfrac{3}{4}$

$\Rightarrow \sin^2 2\theta = \dfrac{3}{4}$

Since $0 < \theta < \dfrac{\pi}{2}$, we have $0 < 2\theta < \pi$, which means $\sin 2\theta > 0$.

Taking the positive square root, we get:

$\sin 2\theta = \dfrac{\sqrt{3}}{2}$

Answer: $\dfrac{\sqrt{3}}{2}$

</details>

### Q4. MHT CET 2026 (18 April Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

Let $f_k(x) = \dfrac{1}{k}(\cos^k x + \sin^k x)$ where $k \in N$, then $f_6(x) - f_4(x) = \ldots$

**Options:**

- **(A)** $\dfrac{1}{6}$
- **(B)** $-\dfrac{1}{12}$
- **(C)** $-\dfrac{1}{6}$
- **(D)** $\dfrac{1}{12}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $-\dfrac{1}{12}$**

**Detailed Solution:**

Given $f_k(x) = \dfrac{1}{k}(\cos^k x + \sin^k x)$

For $k = 6$:
$f_6(x) = \dfrac{1}{6}(\cos^6 x + \sin^6 x)$

Using the identity $a^3 + b^3 = (a+b)^3 - 3ab(a+b)$ with $a = \cos^2 x$ and $b = \sin^2 x$:
$\cos^6 x + \sin^6 x = (\cos^2 x + \sin^2 x)^3 - 3\cos^2 x \sin^2 x(\cos^2 x + \sin^2 x) = 1 - 3\cos^2 x \sin^2 x$

Thus, $f_6(x) = \dfrac{1}{6}(1 - 3\cos^2 x \sin^2 x) = \dfrac{1}{6} - \dfrac{1}{2}\cos^2 x \sin^2 x$

For $k = 4$:
$f_4(x) = \dfrac{1}{4}(\cos^4 x + \sin^4 x)$

Using the identity $a^2 + b^2 = (a+b)^2 - 2ab$ with $a = \cos^2 x$ and $b = \sin^2 x$:
$\cos^4 x + \sin^4 x = (\cos^2 x + \sin^2 x)^2 - 2\cos^2 x \sin^2 x = 1 - 2\cos^2 x \sin^2 x$

Thus, $f_4(x) = \dfrac{1}{4}(1 - 2\cos^2 x \sin^2 x) = \dfrac{1}{4} - \dfrac{1}{2}\cos^2 x \sin^2 x$

Subtracting $f_4(x)$ from $f_6(x)$:
$f_6(x) - f_4(x) = \left(\dfrac{1}{6} - \dfrac{1}{2}\cos^2 x \sin^2 x\right) - \left(\dfrac{1}{4} - \dfrac{1}{2}\cos^2 x \sin^2 x\right)$

$f_6(x) - f_4(x) = \dfrac{1}{6} - \dfrac{1}{4} = \dfrac{2 - 3}{12} = -\dfrac{1}{12}$

Answer: $-\dfrac{1}{12}$

</details>

### Q6. MHT CET 2025 (22 Apr Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

The value of
$\sin ^2 5^{\circ}+\sin ^2 10^{\circ}+\sin ^2 15+\ldots \ldots \ldots \ldots \ldots . .+\sin ^2 85^{\circ}+\sin ^2 90^{\circ}=$

**Options:**

- **(A)** $\frac{19}{2}$
- **(B)** $\frac{3}{2}$
- **(C)** $\frac{23}{2}$
- **(D)** $\frac{21}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $\frac{19}{2}$**

**Detailed Solution:**

The given series is $S = \sin^2 5^{\circ} + \sin^2 10^{\circ} + \sin^2 15^{\circ} + \dots + \sin^2 85^{\circ} + \sin^2 90^{\circ}$.

The angles are in an arithmetic progression with a common difference of $5^{\circ}$. The number of terms is $\dfrac{90}{5} = 18$.

We can group the terms from the beginning and the end (excluding $45^{\circ}$ and $90^{\circ}$) as follows:

$S = (\sin^2 5^{\circ} + \sin^2 85^{\circ}) + (\sin^2 10^{\circ} + \sin^2 80^{\circ}) + \dots + (\sin^2 40^{\circ} + \sin^2 50^{\circ}) + \sin^2 45^{\circ} + \sin^2 90^{\circ}$

Using the complementary angle identity $\sin(90^{\circ} - \theta) = \cos \theta$, we have $\sin^2 85^{\circ} = \cos^2 5^{\circ}$, $\sin^2 80^{\circ} = \cos^2 10^{\circ}$, and so on.

$S = (\sin^2 5^{\circ} + \cos^2 5^{\circ}) + (\sin^2 10^{\circ} + \cos^2 10^{\circ}) + \dots + (\sin^2 40^{\circ} + \cos^2 40^{\circ}) + \sin^2 45^{\circ} + \sin^2 90^{\circ}$

Since $\sin^2 \theta + \cos^2 \theta = 1$, each of the $8$ pairs sums to $1$.

$S = 8(1) + \left(\dfrac{1}{\sqrt{2}}\right)^2 + (1)^2$

$S = 8 + \dfrac{1}{2} + 1$

$S = 9 + \dfrac{1}{2} = \dfrac{19}{2}$

Answer: $\frac{19}{2}$

</details>

### Q7. MHT CET 2024 (16 May Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

The value of $\cos 20^{\circ}+2 \sin ^2 55^{\circ}-\sqrt{2} \sin 65^{\circ}$ is

**Options:**

- **(A)** 0
- **(B)** 1
- **(C)** -1
- **(D)** $\frac{1}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) 1**

**Detailed Solution:**

Using the identity $2 \sin^2 \theta = 1 - \cos 2\theta$, we have $2 \sin^2 55^{\circ} = 1 - \cos 110^{\circ}$.

The given expression becomes:
$\cos 20^{\circ} + 1 - \cos 110^{\circ} - \sqrt{2} \sin 65^{\circ}$

Rearranging the terms, we get:
$1 + (\cos 20^{\circ} - \cos 110^{\circ}) - \sqrt{2} \sin 65^{\circ}$

Using the formula $\cos C - \cos D = 2 \sin\left(\dfrac{C+D}{2}\right) \sin\left(\dfrac{D-C}{2}\right)$, we get:
$\cos 20^{\circ} - \cos 110^{\circ} = 2 \sin\left(\dfrac{20^{\circ}+110^{\circ}}{2}\right) \sin\left(\dfrac{110^{\circ}-20^{\circ}}{2}\right)$

$= 2 \sin 65^{\circ} \sin 45^{\circ}$

$= 2 \sin 65^{\circ} \left(\dfrac{1}{\sqrt{2}}\right)$

$= \sqrt{2} \sin 65^{\circ}$

Substituting this back into the expression, we get:
$1 + \sqrt{2} \sin 65^{\circ} - \sqrt{2} \sin 65^{\circ} = 1$

Answer: 1

</details>

### Q8. MHT CET 2024 (11 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

If the sides of a triangle $a, b, c$ are in A.P., then with usual notations, a $\cos ^2 \frac{\mathrm{C}}{2}+\mathrm{c} \cos ^2 \frac{\mathrm{~A}}{2}$ is

**Options:**

- **(A)** $\frac{3 a}{2}$
- **(B)** $\frac{3 \mathrm{c}}{2}$
- **(C)** $\frac{3 b}{2}$
- **(D)** $\frac{\mathrm{a}+\mathrm{c}}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $\frac{3 b}{2}$**

**Detailed Solution:**

Using the trigonometric identity $\cos^2 \theta = \dfrac{1 + \cos 2\theta}{2}$, we can write the given expression as:

$a \cos^2 \dfrac{C}{2} + c \cos^2 \dfrac{A}{2} = a \left( \dfrac{1 + \cos C}{2} \right) + c \left( \dfrac{1 + \cos A}{2} \right)$

$= \dfrac{a + c}{2} + \dfrac{a \cos C + c \cos A}{2}$

By the projection formula, $a \cos C + c \cos A = b$. Substituting this, we get:

$= \dfrac{a + c + b}{2}$

Since the sides $a, b, c$ are in A.P., we have $a + c = 2b$. Substituting this into the expression:

$= \dfrac{2b + b}{2} = \dfrac{3b}{2}$

Answer: $\frac{3 b}{2}$

</details>

### Q9. MHT CET 2024 (11 May Shift 1)

*Type:* `singleCorrect` | *Level:* `3`

$\cos ^3\left(\frac{\pi}{8}\right) \cos \left(\frac{3 \pi}{8}\right)+\sin ^3\left(\frac{\pi}{8}\right) \sin \left(\frac{3 \pi}{8}\right)=$

**Options:**

- **(A)** $\frac{1}{2 \sqrt{2}}$
- **(B)** $\frac{1}{\sqrt{2}}$
- **(C)** $\frac{1}{2}$
- **(D)** $\frac{\sqrt{3}}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $\frac{1}{2 \sqrt{2}}$**

**Detailed Solution:**

Let $\theta = \dfrac{\pi}{8}$. Then $\dfrac{3\pi}{8} = \dfrac{\pi}{2} - \dfrac{\pi}{8} = \dfrac{\pi}{2} - \theta$.

The given expression becomes:

$\cos^3\theta \cos\left(\dfrac{\pi}{2} - \theta\right) + \sin^3\theta \sin\left(\dfrac{\pi}{2} - \theta\right)$

Using $\cos\left(\dfrac{\pi}{2} - \theta\right) = \sin\theta$ and $\sin\left(\dfrac{\pi}{2} - \theta\right) = \cos\theta$, we get:

$\cos^3\theta \sin\theta + \sin^3\theta \cos\theta$

Taking $\sin\theta \cos\theta$ common:

$\sin\theta \cos\theta (\cos^2\theta + \sin^2\theta)$

Since $\cos^2\theta + \sin^2\theta = 1$, this simplifies to:

$\sin\theta \cos\theta = \dfrac{1}{2}(2\sin\theta \cos\theta) = \dfrac{1}{2}\sin(2\theta)$

Substituting $\theta = \dfrac{\pi}{8}$:

$\dfrac{1}{2}\sin\left(2 \times \dfrac{\pi}{8}\right) = \dfrac{1}{2}\sin\left(\dfrac{\pi}{4}\right)$

$\dfrac{1}{2} \times \dfrac{1}{\sqrt{2}} = \dfrac{1}{2\sqrt{2}}$

Answer: $\frac{1}{2 \sqrt{2}}$

</details>
