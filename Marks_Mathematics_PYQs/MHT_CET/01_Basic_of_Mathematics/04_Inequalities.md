### Q1. MHT CET 2026 (20 April Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

The statement having truth value 'T' from the following is

**Options:**

- **(A)** $\sin(x)$ is an even function.
- **(B)** Every square matrix is non-singular.
- **(C)** The product of complex number and its conjugate is purely imaginary.
- **(D)** A square of any real number is non-negative.

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) A square of any real number is non-negative.**

**Detailed Solution:**

Evaluating statement (1): $\sin(-x) = -\sin(x)$, which means $\sin(x)$ is an odd function. The statement is false.

Evaluating statement (2): A square matrix with a zero determinant is a singular matrix. Therefore, not every square matrix is non-singular. The statement is false.

Evaluating statement (3): Let a complex number be $z = x + iy$, its conjugate is $\bar{z} = x - iy$. The product $z\bar{z} = (x + iy)(x - iy) = x^2 + y^2$, which is a purely real number. The statement is false.

Evaluating statement (4): For any real number $x$, the square is $x^2 \ge 0$. The square of any real number is non-negative. The statement is true.

</details>

### Q2. MHT CET 2026 (11 April Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

If $A = \{1, 2, 3, 4, 5\}$, then which of the following statements is not true?

**Options:**

- **(A)** $\exists x \in A$, such that $x + 4 \leq 9$
- **(B)** $\exists x \in A$, such that $12 - x = 7$
- **(C)** $\forall x \in A, x + 3 \geq 4$
- **(D)** $\exists x \in A$, such that $x + 2 < 3$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $\exists x \in A$, such that $x + 2 < 3$**

**Detailed Solution:**

Given the set $A = \{1, 2, 3, 4, 5\}$.

Checking the first statement: $\exists x \in A$, such that $x + 4 \leq 9$. For $x = 1$, $1 + 4 = 5 \leq 9$. This statement is true.

Checking the second statement: $\exists x \in A$, such that $12 - x = 7$. Solving for $x$ gives $x = 5$. Since $5 \in A$, this statement is true.

Checking the third statement: $\forall x \in A, x + 3 \geq 4$. The minimum value of $x$ in $A$ is $1$. For $x = 1$, $1 + 3 = 4 \geq 4$. For all other values in $A$, $x + 3 > 4$. This statement is true.

Checking the fourth statement: $\exists x \in A$, such that $x + 2 < 3$. Solving for $x$ gives $x < 1$. There is no element in $A$ that is strictly less than $1$. This statement is false.

Therefore, the fourth statement is not true.

Answer: $\exists x \in A$, such that $x + 2 < 3$

</details>

### Q4. MHT CET 2020 (12 Oct Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

If $|3 x-2| \leq \frac{1}{2} \quad$ then $x \in$

**Options:**

- **(A)** $\left[\frac{1}{2}, \frac{5}{6}\right]$
- **(B)** $\left(\frac{1}{2}, \frac{5}{6}\right]$
- **(C)** $\left[\frac{1}{2}, \frac{5}{6}\right)$
- **(D)** $\left(\frac{1}{2}, \frac{5}{6}\right)$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $\left[\frac{1}{2}, \frac{5}{6}\right]$**

**Detailed Solution:**

We have $|3 x-2| \leq \frac{1}{2}$
$\therefore \frac{-1}{2} \leq(3 x-2) \leq \frac{1}{2}$
$\therefore \frac{-1}{2} \leq 3 x-2 \quad$ and $\quad 3 x-2 \leq \frac{1}{2}$
$\therefore \quad \frac{3}{2} \leq 3 x \quad$ and $\quad 3 x \leq \frac{5}{2}$
$\quad \frac{1}{2} \leq x \quad$ and $\quad x \leq \frac{5}{6}$
$\therefore x \in\left[\frac{1}{2}, \frac{5}{6}\right]$

</details>
