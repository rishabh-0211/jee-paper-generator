### Q1. MHT CET 2026 (19 May Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

If $a$ and $b$ are respectively the minimum and maximum values of the expression $f(x) = (\sin^{-1} x + 2\cos^{-1} x)$, then $a + b$ is equal to...

**Options:**

- **(A)** $\dfrac{\pi}{2}$
- **(B)** $\pi$
- **(C)** $\dfrac{3\pi}{2}$
- **(D)** $2\pi$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $2\pi$**

**Detailed Solution:**

The given expression is $f(x) = \sin^{-1} x + 2\cos^{-1} x$

Using the inverse trigonometric identity $\sin^{-1} x + \cos^{-1} x = \dfrac{\pi}{2}$, we can rewrite the expression as:

$f(x) = (\sin^{-1} x + \cos^{-1} x) + \cos^{-1} x = \dfrac{\pi}{2} + \cos^{-1} x$

The domain of $f(x)$ is $x \in [-1, 1]$.

The range of the principal value branch of $\cos^{-1} x$ is $[0, \pi]$.

The minimum value of $f(x)$ occurs when $\cos^{-1} x$ is minimum, which is $0$ at $x = 1$.

$a = \dfrac{\pi}{2} + 0 = \dfrac{\pi}{2}$

The maximum value of $f(x)$ occurs when $\cos^{-1} x$ is maximum, which is $\pi$ at $x = -1$.

$b = \dfrac{\pi}{2} + \pi = \dfrac{3\pi}{2}$

The sum $a + b$ is:

$a + b = \dfrac{\pi}{2} + \dfrac{3\pi}{2} = 2\pi$

Answer: $2\pi$

</details>

### Q2. MHT CET 2026 (13 May Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

If $\sin^{-1}\left(\dfrac{x}{5}\right) + \csc^{-1}\left(\dfrac{5}{4}\right) = \dfrac{\pi}{2}$, then the value of $x$ is

**Options:**

- **(A)** $4$
- **(B)** $5$
- **(C)** $3$
- **(D)** $1$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $3$**

**Detailed Solution:**

Given equation: $\sin^{-1}\left(\dfrac{x}{5}\right) + \csc^{-1}\left(\dfrac{5}{4}\right) = \dfrac{\pi}{2}$

Using the property $\csc^{-1}(y) = \sin^{-1}\left(\dfrac{1}{y}\right)$, we get $\csc^{-1}\left(\dfrac{5}{4}\right) = \sin^{-1}\left(\dfrac{4}{5}\right)$.

Substituting this into the equation:

$\sin^{-1}\left(\dfrac{x}{5}\right) + \sin^{-1}\left(\dfrac{4}{5}\right) = \dfrac{\pi}{2}$

$\sin^{-1}\left(\dfrac{x}{5}\right) = \dfrac{\pi}{2} - \sin^{-1}\left(\dfrac{4}{5}\right)$

Using the identity $\sin^{-1}(z) + \cos^{-1}(z) = \dfrac{\pi}{2}$, we have:

$\sin^{-1}\left(\dfrac{x}{5}\right) = \cos^{-1}\left(\dfrac{4}{5}\right)$

Let $\cos^{-1}\left(\dfrac{4}{5}\right) = \theta$, then $\cos\theta = \dfrac{4}{5}$.

Since $\theta$ is in the first quadrant, $\sin\theta = \sqrt{1 - \cos^2\theta} = \sqrt{1 - \left(\dfrac{4}{5}\right)^2} = \dfrac{3}{5}$.

Thus, $\cos^{-1}\left(\dfrac{4}{5}\right) = \sin^{-1}\left(\dfrac{3}{5}\right)$.

Equating the two expressions:

$\sin^{-1}\left(\dfrac{x}{5}\right) = \sin^{-1}\left(\dfrac{3}{5}\right)$

$\dfrac{x}{5} = \dfrac{3}{5}$

$x = 3$

Answer: $3$

</details>

$\dfrac{E + 4}{4} + \dfrac{E - 4}{6} = \dfrac{\pi}{2}$

$\dfrac{3(E + 4) + 2(E - 4)}{12} = \dfrac{\pi}{2}$

$\dfrac{5E + 4}{12} = \dfrac{\pi}{2}$

$5E + 4 = 6\pi$

$E = \dfrac{6\pi - 4}{5}$

### Q4. MHT CET 2026 (18 April Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

For $x > 0$, if $\sin(\cos^{-1}x + \tan^{-1}x) - \cos(\sin^{-1}x + \tan^{-1}x) = \sin(\cot^{-1}2)$ then $x = $

**Options:**

- **(A)** $\dfrac{1}{\sqrt{2}}$
- **(B)** $\dfrac{1}{2}$
- **(C)** $\dfrac{\sqrt{3}}{2}$
- **(D)** $1$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\dfrac{1}{2}$**

**Detailed Solution:**

Given equation: $\sin(\cos^{-1}x + \tan^{-1}x) - \cos(\sin^{-1}x + \tan^{-1}x) = \sin(\cot^{-1}2)$

Let $\alpha = \cos^{-1}x$ and $\gamma = \tan^{-1}x$.

We know that $\sin^{-1}x + \cos^{-1}x = \dfrac{\pi}{2}$, so $\sin^{-1}x = \dfrac{\pi}{2} - \alpha$.

The second term on the left hand side becomes $\cos\left(\dfrac{\pi}{2} - \alpha + \gamma\right) = \sin(\alpha - \gamma)$.

The left hand side simplifies to $\sin(\alpha + \gamma) - \sin(\alpha - \gamma) = 2 \cos\alpha \sin\gamma$.

Since $\alpha = \cos^{-1}x$, we have $\cos\alpha = x$.

Since $\gamma = \tan^{-1}x$, we have $\sin\gamma = \dfrac{x}{\sqrt{1+x^2}}$.

Thus, the left hand side is $2x \left( \dfrac{x}{\sqrt{1+x^2}} \right) = \dfrac{2x^2}{\sqrt{1+x^2}}$.

For the right hand side, let $\theta = \cot^{-1}2$, then $\cot\theta = 2$, which gives $\sin\theta = \dfrac{1}{\sqrt{1+\cot^2\theta}} = \dfrac{1}{\sqrt{5}}$.

Equating both sides:

$\dfrac{2x^2}{\sqrt{1+x^2}} = \dfrac{1}{\sqrt{5}}$

Squaring both sides:

$\dfrac{4x^4}{1+x^2} = \dfrac{1}{5}$

$20x^4 = 1 + x^2$

$20x^4 - x^2 - 1 = 0$

$(5x^2 + 1)(4x^2 - 1) = 0$

Since $x^2 > 0$, we must have $4x^2 - 1 = 0 \Rightarrow x^2 = \dfrac{1}{4}$.

Given $x > 0$, we get $x = \dfrac{1}{2}$.

Answer: $\dfrac{1}{2}$

</details>

### Q5. MHT CET 2026 (18 April Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

If $0 \leq x \leq 1$, $I_1 = \int\sin^{-1}\sqrt{1-x^2}\,dx$ and $I_2 = \int\sin^{-1}x\,dx$, then which of the following is true?

**Options:**

- **(A)** $I_1 = I_2$
- **(B)** $I_1 = \dfrac{\pi}{2}I_2$
- **(C)** $I_1 + I_2 = \dfrac{\pi}{2}x$
- **(D)** $I_1 + I_2 = \dfrac{\pi}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $I_1 + I_2 = \dfrac{\pi}{2}x$**

**Detailed Solution:**

For $0 \leq x \leq 1$, the inverse trigonometric identity is:

$\sin^{-1}\sqrt{1-x^2} = \cos^{-1}x$

Substituting this into $I_1$:

$I_1 = \int \cos^{-1}x \,dx$

Given:

$I_2 = \int \sin^{-1}x \,dx$

Adding $I_1$ and $I_2$:

$I_1 + I_2 = \int \cos^{-1}x \,dx + \int \sin^{-1}x \,dx$

$I_1 + I_2 = \int (\cos^{-1}x + \sin^{-1}x) \,dx$

Using the identity $\sin^{-1}x + \cos^{-1}x = \dfrac{\pi}{2}$:

$I_1 + I_2 = \int \dfrac{\pi}{2} \,dx$

$I_1 + I_2 = \dfrac{\pi}{2}x$

Answer: $I_1 + I_2 = \dfrac{\pi}{2}x$

### Q6. MHT CET 2026 (18 April Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

If $0 \leq x \leq 1$ and $(\sin^{-1}x)^3 + (\cos^{-1}x)^3 = a\pi^3$ then

**Options:**

- **(A)** $a \geq \dfrac{1}{32}$
- **(B)** $a \geq \dfrac{1}{16}$
- **(C)** $a \leq \dfrac{1}{32}$
- **(D)** $a \leq \dfrac{1}{16}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $a \geq \dfrac{1}{32}$**

**Detailed Solution:**

Let $\sin^{-1}x = y$. Since $0 \leq x \leq 1$, we have $0 \leq y \leq \dfrac{\pi}{2}$.

We know that $\cos^{-1}x = \dfrac{\pi}{2} - \sin^{-1}x = \dfrac{\pi}{2} - y$.

The given equation is:

$y^3 + \left(\dfrac{\pi}{2} - y\right)^3 = a\pi^3$

Using the identity $A^3 + B^3 = (A+B)(A^2 - AB + B^2)$, we get:

$y^3 + \left(\dfrac{\pi}{2} - y\right)^3 = \left(y + \dfrac{\pi}{2} - y\right) \left( y^2 - y\left(\dfrac{\pi}{2} - y\right) + \left(\dfrac{\pi}{2} - y\right)^2 \right)$

$= \dfrac{\pi}{2} \left( y^2 - \dfrac{\pi}{2}y + y^2 + \dfrac{\pi^2}{4} - \pi y + y^2 \right)$

$= \dfrac{\pi}{2} \left( 3y^2 - \dfrac{3\pi}{2}y + \dfrac{\pi^2}{4} \right)$

$= \dfrac{3\pi}{2} \left( y^2 - \dfrac{\pi}{2}y + \dfrac{\pi^2}{12} \right)$

Completing the square for the quadratic in $y$:

$= \dfrac{3\pi}{2} \left( \left(y - \dfrac{\pi}{4}\right)^2 - \dfrac{\pi^2}{16} + \dfrac{\pi^2}{12} \right)$

$= \dfrac{3\pi}{2} \left( \left(y - \dfrac{\pi}{4}\right)^2 + \dfrac{\pi^2}{48} \right)$

$= \dfrac{3\pi}{2} \left(y - \dfrac{\pi}{4}\right)^2 + \dfrac{\pi^3}{32}$

Since $0 \leq y \leq \dfrac{\pi}{2}$, the minimum value of this expression occurs at $y = \dfrac{\pi}{4}$.

Minimum value $= \dfrac{3\pi}{2} (0) + \dfrac{\pi^3}{32} = \dfrac{\pi^3}{32}$

The maximum value occurs at the endpoints $y = 0$ or $y = \dfrac{\pi}{2}$.

Maximum value $= \dfrac{3\pi}{2} \left(\dfrac{\pi}{4}\right)^2 + \dfrac{\pi^3}{32} = \dfrac{3\pi^3}{32} + \dfrac{\pi^3}{32} = \dfrac{\pi^3}{8}$

Thus, the range of the expression is $\left[\dfrac{\pi^3}{32}, \dfrac{\pi^3}{8}\right]$.

Given that the expression equals $a\pi^3$, we have:

$\dfrac{\pi^3}{32} \leq a\pi^3 \leq \dfrac{\pi^3}{8}$

$\Rightarrow \dfrac{1}{32} \leq a \leq \dfrac{1}{8}$

From the given options, the condition that is always satisfied is $a \geq \dfrac{1}{32}$.

Answer: $a \geq \dfrac{1}{32}$

</details>

### Q7. MHT CET 2026 (16 April Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

If $(\tan^{-1}x)^2 + (\cot^{-1}x)^2 = \dfrac{5\pi^2}{8}$, then the value of $x$ is equal to...

**Options:**

- **(A)** $-1$
- **(B)** $-2$
- **(C)** $1$
- **(D)** $2$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $-1$**

**Detailed Solution:**

Let $\tan^{-1}x = t$. Then $\cot^{-1}x = \dfrac{\pi}{2} - t$.

Substituting in the given equation:

$t^2 + \left(\dfrac{\pi}{2} - t\right)^2 = \dfrac{5\pi^2}{8}$

$2t^2 - \pi t + \dfrac{\pi^2}{4} - \dfrac{5\pi^2}{8} = 0$

$2t^2 - \pi t - \dfrac{3\pi^2}{8} = 0$

$16t^2 - 8\pi t - 3\pi^2 = 0$

$(4t - 3\pi)(4t + \pi) = 0$

$t = \dfrac{3\pi}{4}$ or $t = -\dfrac{\pi}{4}$

Since the principal value branch of $\tan^{-1}x$ is $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$, $t = \dfrac{3\pi}{4}$ is rejected.

Therefore, $\tan^{-1}x = -\dfrac{\pi}{4}$

$x = \tan\left(-\dfrac{\pi}{4}\right) = -1$

Answer: $-1$

</details>

### Q8. MHT CET 2026 (13 April Shift 2)

Let $f(x) = (\sin^{-1} x)^2 + (\cos^{-1} x)^2$ be a real-valued function defined on its domain. Then the sum of the greatest and the least values of $f(x)$ is

**Options:**

- **(A)** $\dfrac{\pi^2}{8}$
- **(B)** $\dfrac{11\pi^2}{8}$
- **(C)** $\dfrac{3\pi^2}{8}$
- **(D)** $\dfrac{7\pi^2}{8}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\dfrac{11\pi^2}{8}$**

**Detailed Solution:**

Given $f(x) = (\sin^{-1} x)^2 + (\cos^{-1} x)^2$ with domain $x \in [-1, 1]$.

Using the identity $\sin^{-1} x + \cos^{-1} x = \dfrac{\pi}{2}$, we can write:

$f(x) = (\sin^{-1} x)^2 + \left(\dfrac{\pi}{2} - \sin^{-1} x\right)^2$

Let $\sin^{-1} x = t$, where $t \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

$f(t) = t^2 + \left(\dfrac{\pi}{2} - t\right)^2 = 2t^2 - \pi t + \dfrac{\pi^2}{4}$

Completing the square, we get:

$f(t) = 2\left(t^2 - \dfrac{\pi}{2}t\right) + \dfrac{\pi^2}{4} = 2\left(t - \dfrac{\pi}{4}\right)^2 - 2\left(\dfrac{\pi^2}{16}\right) + \dfrac{\pi^2}{4}$

$f(t) = 2\left(t - \dfrac{\pi}{4}\right)^2 + \dfrac{\pi^2}{8}$

The minimum value of $f(t)$ occurs at $t = \dfrac{\pi}{4}$, which lies in the interval $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

Minimum value $= \dfrac{\pi^2}{8}$

The maximum value of $f(t)$ occurs at the endpoint furthest from $t = \dfrac{\pi}{4}$, which is $t = -\dfrac{\pi}{2}$.

Maximum value $= 2\left(-\dfrac{\pi}{2} - \dfrac{\pi}{4}\right)^2 + \dfrac{\pi^2}{8} = 2\left(-\dfrac{3\pi}{4}\right)^2 + \dfrac{\pi^2}{8} = \dfrac{9\pi^2}{8} + \dfrac{\pi^2}{8} = \dfrac{5\pi^2}{4}$

The sum of the greatest and the least values of $f(x)$ is:

$\dfrac{5\pi^2}{4} + \dfrac{\pi^2}{8} = \dfrac{10\pi^2}{8} + \dfrac{\pi^2}{8} = \dfrac{11\pi^2}{8}$

Answer: $\dfrac{11\pi^2}{8}$

</details>
