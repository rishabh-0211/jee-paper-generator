### Q1. MHT CET 2026 (15 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

If $\alpha$ and $\beta$ are the solutions of $2\cos\theta = 1$ in the interval $[0, 2\pi)$, then the solutions of $2\cos\theta + \cos(\alpha + \beta) = 0$ in the interval $[0, 2\pi)$ are...

**Options:**

- **(A)** $\dfrac{\pi}{3},\,\dfrac{5\pi}{3}$
- **(B)** $\dfrac{2\pi}{3},\,\dfrac{4\pi}{3}$
- **(C)** $0,\,\pi$
- **(D)** $\dfrac{\pi}{2},\,\dfrac{3\pi}{2}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\dfrac{2\pi}{3},\,\dfrac{4\pi}{3}$**

**Detailed Solution:**

Given $2\cos\theta = 1$, we have $\cos\theta = \dfrac{1}{2}$.

The solutions in the interval $[0, 2\pi)$ are $\alpha = \dfrac{\pi}{3}$ and $\beta = \dfrac{5\pi}{3}$.

Calculating the sum $\alpha + \beta = \dfrac{\pi}{3} + \dfrac{5\pi}{3} = 2\pi$.

The given equation is $2\cos\theta + \cos(\alpha + \beta) = 0$.

Substituting the value of $\alpha + \beta$, we get $2\cos\theta + \cos(2\pi) = 0$.

Since $\cos(2\pi) = 1$, the equation becomes $2\cos\theta + 1 = 0$, which gives $\cos\theta = -\dfrac{1}{2}$.

The solutions for $\cos\theta = -\dfrac{1}{2}$ in the interval $[0, 2\pi)$ are $\theta = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}$ and $\theta = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}$.

Answer: $\dfrac{2\pi}{3},\,\dfrac{4\pi}{3}$

</details>

### Q2. MHT CET 2026 (13 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

The general solution of the equation $2\sin^2 x + \sin^2 2x = 2$ is $x = (2n+1)\alpha$ or $x = m\pi \pm \beta$, $m, n \in \mathbb{Z}$, then $\alpha$ and $\beta$ are the roots of the quadratic equation _______

**Options:**

- **(A)** $8x^2 - 6\pi x + \pi^2 = 0$
- **(B)** $4x^2 - 6\pi x + \pi^2 = 0$
- **(C)** $8x^2 + 6\pi x + \pi^2 = 0$
- **(D)** $4x^2 + 6\pi x + \pi^2 = 0$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $8x^2 - 6\pi x + \pi^2 = 0$**

**Detailed Solution:**

Given equation: $2\sin^2 x + \sin^2 2x = 2$

$2\sin^2 x + (2\sin x \cos x)^2 = 2$

$2\sin^2 x + 4\sin^2 x \cos^2 x = 2$

Dividing by $2$:

$\sin^2 x + 2\sin^2 x \cos^2 x = 1$

$2\sin^2 x \cos^2 x = 1 - \sin^2 x$

$2\sin^2 x \cos^2 x = \cos^2 x$

$\cos^2 x (2\sin^2 x - 1) = 0$

This gives two cases:

Case 1: $\cos^2 x = 0 \Rightarrow \cos x = 0$

$x = (2n+1)\dfrac{\pi}{2}$, where $n \in \mathbb{Z}$

Comparing with $x = (2n+1)\alpha$, we get $\alpha = \dfrac{\pi}{2}$.

Case 2: $2\sin^2 x - 1 = 0 \Rightarrow \sin^2 x = \dfrac{1}{2}$

$\sin^2 x = \sin^2 \dfrac{\pi}{4}$

$x = m\pi \pm \dfrac{\pi}{4}$, where $m \in \mathbb{Z}$

Comparing with $x = m\pi \pm \beta$, we get $\beta = \dfrac{\pi}{4}$.

The roots of the required quadratic equation are $\alpha = \dfrac{\pi}{2}$ and $\beta = \dfrac{\pi}{4}$.

Sum of roots: $S = \dfrac{\pi}{2} + \dfrac{\pi}{4} = \dfrac{3\pi}{4}$

Product of roots: $P = \dfrac{\pi}{2} \times \dfrac{\pi}{4} = \dfrac{\pi^2}{8}$

The quadratic equation is $x^2 - Sx + P = 0$

$x^2 - \dfrac{3\pi}{4}x + \dfrac{\pi^2}{8} = 0$

$8x^2 - 6\pi x + \pi^2 = 0$

Answer: $8x^2 - 6\pi x + \pi^2 = 0$

</details>

### Q4. MHT CET 2026 (12 May Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

If $\tan\theta+\tan 2\theta+\tan 3\theta=\tan\theta\tan 2\theta\tan 3\theta$, then the most general value of $\theta$ for which all terms in the equation are defined is ...

**Options:**

- **(A)** $\theta=\dfrac{n\pi}{6}, n\in Z$
- **(B)** $\theta=\dfrac{n\pi}{3}, n\in Z$
- **(C)** $\theta=\dfrac{n\pi}{2}, n\in Z$
- **(D)** $\theta=n\pi\pm\dfrac{\pi}{3}, n\in Z$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) $\theta=\dfrac{n\pi}{3}, n\in Z$**

**Detailed Solution:**

The given equation is $\tan\theta + \tan 2\theta + \tan 3\theta = \tan\theta \tan 2\theta \tan 3\theta$

Rearranging the terms, we get:

$\tan\theta + \tan 2\theta = -\tan 3\theta (1 - \tan\theta \tan 2\theta)$

For the terms in the equation to be defined, $\tan 3\theta$ must be defined, which means $3\theta \neq (2k+1)\dfrac{\pi}{2}$, so $\theta \neq (2k+1)\dfrac{\pi}{6}$.

If $1 - \tan\theta \tan 2\theta = 0$, then $\tan\theta \left(\dfrac{2\tan\theta}{1-\tan^2\theta}\right) = 1 \Rightarrow 3\tan^2\theta = 1 \Rightarrow \theta = k\pi \pm \dfrac{\pi}{6}$.

For these values, $3\theta = 3k\pi \pm \dfrac{\pi}{2}$, making $\tan 3\theta$ undefined. Thus, $1 - \tan\theta \tan 2\theta \neq 0$.

Dividing both sides by $1 - \tan\theta \tan 2\theta$, we get:

$\dfrac{\tan\theta + \tan 2\theta}{1 - \tan\theta \tan 2\theta} = -\tan 3\theta$

$\Rightarrow \tan(\theta + 2\theta) = -\tan 3\theta$

$\Rightarrow \tan 3\theta = -\tan 3\theta$

$\Rightarrow 2\tan 3\theta = 0$

$\Rightarrow \tan 3\theta = 0$

$\Rightarrow 3\theta = n\pi$

$\Rightarrow \theta = \dfrac{n\pi}{3}, n \in Z$

For $\theta = \dfrac{n\pi}{3}$, the terms $\tan\theta$, $\tan 2\theta$, and $\tan 3\theta$ are all defined.

Answer: $\theta=\dfrac{n\pi}{3}, n\in Z$

</details>

### Q7. MHT CET 2025 (5 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

The general solutions of the equation $\tan ^2 \theta+\sec 2 \theta=1$ are

**Options:**

- **(A)** $n \pi, n \pi \pm \frac{\pi}{3}, n \in \mathbb{Z}$
- **(B)** $n \pi, n \pi \pm \frac{\pi}{4}, n \in \mathbb{Z}$
- **(C)** $\frac{n \pi}{4}, \frac{n \pi}{4} \pm \frac{\pi}{3}, n \in \mathbb{Z}$
- **(D)** $\mathrm{n} \pi, \mathrm{n} \pi \pm \frac{\pi}{6}, \mathrm{n} \in \mathbb{Z}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $n \pi, n \pi \pm \frac{\pi}{3}, n \in \mathbb{Z}$**

**Detailed Solution:**

Given equation: $\tan^2 \theta + \sec 2\theta = 1$

We know that $\sec 2\theta = \dfrac{1}{\cos 2\theta} = \dfrac{1 + \tan^2 \theta}{1 - \tan^2 \theta}$.

Substituting this into the given equation, we get:

$\tan^2 \theta + \dfrac{1 + \tan^2 \theta}{1 - \tan^2 \theta} = 1$

Let $\tan^2 \theta = t$. The equation becomes:

$t + \dfrac{1 + t}{1 - t} = 1$

Multiplying both sides by $1 - t$ (assuming $t \neq 1$):

$t(1 - t) + 1 + t = 1 - t$

$t - t^2 + 1 + t = 1 - t$

$-t^2 + 2t + 1 = 1 - t$

$t^2 - 3t = 0$

$t(t - 3) = 0$

This gives $t = 0$ or $t = 3$.

Case 1: $t = 0$
$\tan^2 \theta = 0 \Rightarrow \tan \theta = 0$
$\theta = n\pi$, where $n \in \mathbb{Z}$

Case 2: $t = 3$
$\tan^2 \theta = 3$
$\tan^2 \theta = (\sqrt{3})^2 = \tan^2 \left(\dfrac{\pi}{3}\right)$
$\theta = n\pi \pm \dfrac{\pi}{3}$, where $n \in \mathbb{Z}$

Thus, the general solutions are $n\pi$ and $n\pi \pm \dfrac{\pi}{3}$ for $n \in \mathbb{Z}$.

Answer: $n \pi, n \pi \pm \frac{\pi}{3}, n \in \mathbb{Z}$

</details>

### Q8. MHT CET 2025 (26 Apr Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

If $\tan (\pi \cos \theta)=\cot (\pi \sin \theta)$, then $\sin \left(\frac{\pi}{4}+\theta\right)=$

**Options:**

- **(A)** $\frac{1}{2}$
- **(B)** $\frac{1}{\sqrt{2}}$
- **(C)** $\frac{1}{4}$
- **(D)** $\frac{1}{2 \sqrt{2}}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $\frac{1}{2 \sqrt{2}}$**

**Detailed Solution:**

Given $\tan (\pi \cos \theta) = \cot (\pi \sin \theta)$

We can write this as:

$\tan (\pi \cos \theta) = \tan \left(\dfrac{\pi}{2} - \pi \sin \theta\right)$

Equating the angles for the general solution:

$\pi \cos \theta = n\pi + \dfrac{\pi}{2} - \pi \sin \theta$

Dividing the entire equation by $\pi$:

$\cos \theta = n + \dfrac{1}{2} - \sin \theta$

$\cos \theta + \sin \theta = n + \dfrac{1}{2}$

Multiplying both sides by $\dfrac{1}{\sqrt{2}}$:

$\dfrac{1}{\sqrt{2}} \cos \theta + \dfrac{1}{\sqrt{2}} \sin \theta = \dfrac{1}{\sqrt{2}} \left(n + \dfrac{1}{2}\right)$

$\sin \dfrac{\pi}{4} \cos \theta + \cos \dfrac{\pi}{4} \sin \theta = \dfrac{2n + 1}{2\sqrt{2}}$

$\sin \left(\dfrac{\pi}{4} + \theta\right) = \dfrac{2n + 1}{2\sqrt{2}}$

Since the maximum value of $\sin \left(\dfrac{\pi}{4} + \theta\right)$ is $1$ and the minimum is $-1$, the valid integer values for $n$ are $0$ and $-1$.

For $n = 0$:

$\sin \left(\dfrac{\pi}{4} + \theta\right) = \dfrac{1}{2\sqrt{2}}$

For $n = -1$:

$\sin \left(\dfrac{\pi}{4} + \theta\right) = -\dfrac{1}{2\sqrt{2}}$

From the given options, $\dfrac{1}{2\sqrt{2}}$ is the correct choice.

Answer: $\frac{1}{2 \sqrt{2}}$

</details>

$2 \sec x = 2 + \dfrac{1}{2} = \dfrac{5}{2}$

$\cos^2 \dfrac{x}{2} = \dfrac{9}{10}$

$\sin^2 \dfrac{x}{4} = \dfrac{(10 - 3 \sqrt{10})(10 + 3 \sqrt{10})}{20(10 + 3 \sqrt{10})} = \dfrac{100 - 90}{20(10 + 3 \sqrt{10})} = \dfrac{10}{20(10 + 3 \sqrt{10})} = \dfrac{1}{2(10 + 3 \sqrt{10})}$

Since $0 < \dfrac{x}{4} < \dfrac{\pi}{8}$, $\sin \dfrac{x}{4} > 0$:

$\sin \dfrac{x}{4} = \dfrac{1}{\sqrt{2(10 + 3 \sqrt{10})}}$

Since $\tan(x+100^{\circ}) = \tan(x+100^{\circ}-180^{\circ}) = \tan(x-80^{\circ})$, we can rewrite the equation as:

$\dfrac{\tan(x-80^{\circ})}{\tan x} = \tan(x+50^{\circ}) \tan(x-50^{\circ})$

Converting to sine and cosine:

$\dfrac{\sin(x-80^{\circ}) \cos x}{\cos(x-80^{\circ}) \sin x} = \dfrac{\sin(x+50^{\circ}) \sin(x-50^{\circ})}{\cos(x+50^{\circ}) \cos(x-50^{\circ})}$

Multiplying the numerator and denominator of the LHS by $2$ and using the product-to-sum formulas $2\sin A \cos B = \sin(A+B) + \sin(A-B)$, $\sin(A+B)\sin(A-B) = \dfrac{\cos 2B - \cos 2A}{2}$, and $\cos(A+B)\cos(A-B) = \dfrac{\cos 2B + \cos 2A}{2}$:

$\dfrac{\sin(2x-80^{\circ}) - \sin 80^{\circ}}{\sin(2x-80^{\circ}) + \sin 80^{\circ}} = \dfrac{\cos 100^{\circ} - \cos 2x}{\cos 100^{\circ} + \cos 2x}$

$\dfrac{\sin(2x-80^{\circ})}{-\sin 80^{\circ}} = \dfrac{\cos 100^{\circ}}{-\cos 2x}$

$\sin(2x-80^{\circ}) \cos 2x = \sin 80^{\circ} \cos 100^{\circ}$

Multiplying both sides by $2$:

$2 \sin(2x-80^{\circ}) \cos 2x = 2 \sin 80^{\circ} \cos 100^{\circ}$

$\sin(4x-80^{\circ}) + \sin(-80^{\circ}) = \sin(180^{\circ}) + \sin(-20^{\circ})$

$\sin(4x-80^{\circ}) - \sin 80^{\circ} = -\sin 20^{\circ}$

$\sin(4x-80^{\circ}) = \sin 80^{\circ} - \sin 20^{\circ}$

Using the identity $\sin C - \sin D = 2 \cos\left(\dfrac{C+D}{2}\right) \sin\left(\dfrac{C-D}{2}\right)$:

Thus, we have:

$\sin(4x-80^{\circ}) = \sin 40^{\circ}$

The general solution is $4x - 80^{\circ} = n(180^{\circ}) + (-1)^n 40^{\circ}$.

For the smallest positive value of $x$, we take $n=0$:

$4x - 80^{\circ} = 40^{\circ}$

$4x = 120^{\circ} \Rightarrow x = 30^{\circ}$

Answer: $30^{\circ}$
