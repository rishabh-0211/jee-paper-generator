The general solution of the equation $4 \sin x \cos x + 2 \sin x + 2 \cos x + 1 = 0$, where $n \in Z$ is:

**Options:**

- **(A)** $x = 2n\pi \pm \dfrac{2\pi}{3}$ or $n\pi + (-1)^n \dfrac{7\pi}{6}$
- **(B)** $x = 2n\pi \pm \dfrac{\pi}{3}$ or $n\pi - (-1)^n \dfrac{5\pi}{6}$
- **(C)** $x = 2n\pi + \dfrac{\pi}{3}$ or $n\pi + (-1)^n \dfrac{7\pi}{6}$
- **(D)** $x = 2n\pi - \dfrac{\pi}{3}$ or $n\pi + (-1)^n \dfrac{7\pi}{6}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $x = 2n\pi \pm \dfrac{2\pi}{3}$ or $n\pi + (-1)^n \dfrac{7\pi}{6}$**

**Detailed Solution:**

The given equation is $4 \sin x \cos x + 2 \sin x + 2 \cos x + 1 = 0$.

Grouping the terms, we get:

$2 \sin x (2 \cos x + 1) + 1 (2 \cos x + 1) = 0$

$(2 \sin x + 1)(2 \cos x + 1) = 0$

This gives two possible cases:

Case 1: $2 \cos x + 1 = 0$

$\cos x = -\dfrac{1}{2}$

$\cos x = \cos\left(\dfrac{2\pi}{3}\right)$

The general solution is $x = 2n\pi \pm \dfrac{2\pi}{3}$, where $n \in Z$.

$\sin x = -\dfrac{1}{2}$

$\sin x = \sin\left(\dfrac{7\pi}{6}\right)$

The general solution is $x = n\pi + (-1)^n \dfrac{7\pi}{6}$, where $n \in Z$.

Therefore, the general solution is $x = 2n\pi \pm \dfrac{2\pi}{3}$ or $n\pi + (-1)^n \dfrac{7\pi}{6}$.

### Q2. MHT CET 2026 (15 May Shift 2)

*Type:* `singleCorrect` | *Level:* `2`

If $x \in (0, 2\pi)$ satisfies the equation $\cos x + \sin x = \frac{1}{2}$, then the sum of all distinct values of $\tan x$ is...

**Options:**

- **(A)** $-\dfrac{8}{3}$
- **(B)** $0$
- **(C)** $\dfrac{2\sqrt{7}}{3}$
- **(D)** $\dfrac{8}{3}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(A) $-\dfrac{8}{3}$**

**Detailed Solution:**

Given the equation $\cos x + \sin x = \dfrac{1}{2}$.

Squaring both sides:

$(\cos x + \sin x)^2 = \left(\dfrac{1}{2}\right)^2$

$\cos^2 x + \sin^2 x + 2 \sin x \cos x = \dfrac{1}{4}$

$1 + \sin 2x = \dfrac{1}{4}$

$\sin 2x = -\dfrac{3}{4}$

Expressing $\sin 2x$ in terms of $\tan x$:

$\dfrac{2 \tan x}{1 + \tan^2 x} = -\dfrac{3}{4}$

$8 \tan x = -3(1 + \tan^2 x)$

$8 \tan x = -3 - 3 \tan^2 x$

$3 \tan^2 x + 8 \tan x + 3 = 0$

This is a quadratic equation in $\tan x$. Let its roots be $\tan x_1$ and $\tan x_2$.

For any real root $p$ of this equation, there exist angles in $(0, 2\pi)$ such that $\tan x = p$, providing solutions for both $\cos x + \sin x = \dfrac{1}{2}$ and $\cos x + \sin x = -\dfrac{1}{2}$ in different quadrants. Thus, both roots correspond to valid distinct values of $\tan x$ for the original equation.

The sum of all distinct values of $\tan x$ is the sum of the roots of the quadratic equation.

$\text{Sum of roots} = -\dfrac{8}{3}$

</details>

The number of solutions of $\cos 2x = \cos x$ in the interval $[0, 2\pi]$ is

**Options:**

### Q4. MHT CET 2026 (14 May Shift 1)

*Type:* `singleCorrect` | *Level:* `2`

The general solution of the equation $\tan x + \sec x = 2\cos x$ is

**Options:**

- **(A)** $x = n\pi + (-1)^n\left(\dfrac{\pi}{3}\right),\quad n \in Z$
- **(B)** $x = n\pi + (-1)^{n+1}\left(\dfrac{\pi}{2}\right),\quad n \in Z$
- **(C)** $x = n\pi + (-1)^n\left(\dfrac{\pi}{4}\right),\quad n \in Z$
- **(D)** $x = n\pi + (-1)^n\left(\dfrac{\pi}{6}\right),\quad n \in Z$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $x = n\pi + (-1)^n\left(\dfrac{\pi}{6}\right),\quad n \in Z$**

**Detailed Solution:**

The given equation is $\tan x + \sec x = 2\cos x$.

Rewriting in terms of sine and cosine, we get:

$\dfrac{\sin x}{\cos x} + \dfrac{1}{\cos x} = 2\cos x$

For the equation to be defined, $\cos x \neq 0$. Multiplying both sides by $\cos x$ gives:

$\sin x + 1 = 2\cos^2 x$

Using the identity $\cos^2 x = 1 - \sin^2 x$, we have:

$\sin x + 1 = 2(1 - \sin^2 x)$

$2\sin^2 x + \sin x - 1 = 0$

Factoring the quadratic equation in terms of $\sin x$:

$(2\sin x - 1)(\sin x + 1) = 0$

This yields $\sin x = \dfrac{1}{2}$ or $\sin x = -1$.

If $\sin x = -1$, then $\cos x = 0$, which makes $\tan x$ and $\sec x$ undefined. Thus, we reject $\sin x = -1$.

For $\sin x = \dfrac{1}{2}$, the principal value is $\dfrac{\pi}{6}$.

The general solution is:

$x = n\pi + (-1)^n\left(\dfrac{\pi}{6}\right), \quad n \in Z$

Answer: $x = n\pi + (-1)^n\left(\dfrac{\pi}{6}\right),\quad n \in Z$

$3\sin\theta - 4\sin^3\theta - (1 - \sin^2\theta) = \dfrac{1}{4}$

Multiplying by $4$ and rearranging the terms:

$12\sin\theta - 16\sin^3\theta - 4 + 4\sin^2\theta = 1$

$16\sin^3\theta - 4\sin^2\theta - 12\sin\theta + 5 = 0$

Let $\sin\theta = x$. Since $\theta \in [0, \pi]$, we must have $x \in [0, 1]$. The equation becomes:

$16x^3 - 4x^2 - 12x + 5 = 0$

By inspection, $x = \dfrac{1}{2}$ is a root. Factoring out $(2x - 1)$:

$(2x - 1)(8x^2 + 2x - 5) = 0$

The roots are $x = \dfrac{1}{2}$ and the solutions to $8x^2 + 2x - 5 = 0$. Using the quadratic formula:

$x = \dfrac{-2 \pm \sqrt{4 - 4(8)(-5)}}{16} = \dfrac{-2 \pm \sqrt{164}}{16} = \dfrac{-1 \pm \sqrt{41}}{8}$

Since $\sqrt{41} \approx 6.4$, the roots are approximately $x \approx 0.675$ and $x \approx -0.925$.

The valid values for $x = \sin\theta$ in the interval $[0, 1]$ are $x = \dfrac{1}{2}$ and $x = \dfrac{\sqrt{41} - 1}{8}$.

For each value of $\sin\theta \in (0, 1)$, there are exactly $2$ solutions in the interval $[0, \pi]$.

Therefore, the total number of solutions is $2 + 2 = 4$.

Answer: $4$
