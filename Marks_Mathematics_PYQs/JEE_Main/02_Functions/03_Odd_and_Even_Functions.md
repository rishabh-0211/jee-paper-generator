### Q2. JEE Main 2014 (11 Apr Online)

*Type:* `singleCorrect` | *Level:* `1`

Let $\mathrm{f}$ be an odd function defined on the set of real numbers such that for $\mathrm{x} \geq 0$, $f(x)=3 \sin x+4 \cos x$.
Then $\mathrm{f}(\mathrm{x})$ at $\mathrm{x}=-\frac{11 \pi}{6}$ is equal to:

**Options:**

- **(A)** $\frac{3}{2}+2 \sqrt{3}$
- **(B)** $-\frac{3}{2}+2 \sqrt{3}$
- **(C)** $\frac{3}{2}-2 \sqrt{3}$
- **(D)** $-\frac{3}{2}-2 \sqrt{3}$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $\frac{3}{2}-2 \sqrt{3}$**

**Detailed Solution:**

Given $\mathrm{f}$ be an odd function $f(x)=3 \sin x+4 \cos x$
Now,
$$
\begin{array}{r}
f\left(\frac{-11 \pi}{6}\right)=3 \sin \left(\frac{-11 \pi}{6}\right)+4 \cos \left(\frac{-11 \pi}{6}\right) \\
f\left(\frac{-11 \pi}{6}\right)=3 \sin \left(-2 \pi+\frac{\pi}{6}\right)+4 \cos \left(-2 \pi+\frac{\pi}{6}\right) \\
f\left(\frac{-11 \pi}{6}\right)=3 \sin \left\{-\left(2 \pi-\frac{\pi}{6}\right)\right\}+4 \cos \left\{-\left(2 \pi-\frac{\pi}{6}\right)\right\} \\
\left\{\text { For odd functions } \begin{array}{l}
\sin (-\theta)=-\sin \theta \\
\text { and } \cos (-\theta)=-\cos \theta
\end{array}\right\}
\end{array}
$$

$$
\begin{aligned}
\therefore f\left(\frac{-11 \pi}{6}\right)=-3 \sin \left(2 \pi-\frac{\pi}{6}\right)-4 \cos \left(2 \pi-\frac{\pi}{6}\right) \\
\Rightarrow f\left(\frac{-11 \pi}{6}\right) &=+3 \sin \left(\frac{\pi}{6}\right)-4 \cos \frac{\pi}{6} \\
\Rightarrow f\left(\frac{-11 \pi}{6}\right) &=3 \times \frac{1}{2}-4 \times \frac{\sqrt{3}}{2} \\
\text { or } f\left(\frac{-11 \pi}{6}\right) &=\frac{3}{2}-2 \sqrt{3}
\end{aligned}
$$

</details>

### Q3. JEE Main 2003

*Type:* `singleCorrect` | *Level:* `1`

The function $f(x)=\log \left(x+\sqrt{x^2+1}\right)$, is

**Options:**

- **(A)** neither an even nor an odd function
- **(B)** an even function
- **(C)** an odd function
- **(D)** a periodic function

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) an odd function**

**Detailed Solution:**

$f(x)=\log \left(x+\sqrt{x^2+1}\right)$
$f(-x)=-\log \left(x+\sqrt{x^2+1}\right)$
$f(-x)=-f(x)$, i.e., $f(x)$ is an odd function.

</details>
