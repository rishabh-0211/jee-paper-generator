### Q3. JEE Main 2011

*Type:* `singleCorrect` | *Level:* `2`

If $A=\sin ^2 x+\cos ^4 x$, then for all real $x$

**Options:**

- **(A)** $\frac{13}{16} \leq \mathrm{A} \leq 1$
- **(B)** $1 \leq \mathrm{A} \leq 2$
- **(C)** $\frac{3}{4} \leq \mathrm{A} \leq \frac{13}{16}$
- **(D)** $\frac{3}{4} \leq \mathrm{A} \leq 1$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $\frac{3}{4} \leq \mathrm{A} \leq 1$**

**Detailed Solution:**

$A=\sin ^2 x+\cos ^4 x=\frac{7+\cos 4 x}{8} \Rightarrow \frac{3}{4} \leq A \leq 1$

</details>
