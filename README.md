# JEE & Entrance Exam Paper Generator (PCM)

A web application to generate customized JEE Main, JEE Advanced, and BITSAT exam papers with KaTeX equations, official answer keys, step-by-step solutions, and clean PDF / Word export.

- **Subjects**: Physics, Chemistry, Mathematics
- **Question Bank**: 51,000+ PYQs + 32 ExamSIDE Chapters
- **Exports**: Print-ready PDF & Microsoft Word (.docx)
