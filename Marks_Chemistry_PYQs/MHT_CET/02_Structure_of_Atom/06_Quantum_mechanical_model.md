### Q1. MHT CET 2026 (15 May Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

What is a correct set of four quantum number values for an electron present in $3p$ orbital?

**Options:**

- **(A)** $3,\,2,\,1,\,+1/2$
- **(B)** $3,\,2,\,0,\,+1/2$
- **(C)** $3,\,1,\,0,\,+1/2$
- **(D)** $3,\,0,\,1,\,+1/2$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) $3,\,1,\,0,\,+1/2$**

**Detailed Solution:**

For an electron in a $3p$ orbital, the principal quantum number $n = 3$.

The azimuthal quantum number $l = 1$ for a $p$ subshell.

The magnetic quantum number $m$ can take values from $-l$ to $+l$, which means $m = -1, 0, +1$.

The spin quantum number $s$ can be $+1/2$ or $-1/2$.

Comparing with the given options, the set $3, 1, 0, +1/2$ correctly represents an electron in a $3p$ orbital.

Answer: $3,\,1,\,0,\,+1/2$

</details>

### Q3. MHT CET 2026 (12 May Shift 1)

*Type:* `singleCorrect` | *Level:* `1`

Which of the following sets of quantum numbers is incorrect for an electron in an atom?

**Options:**

- **(A)** $n=1, l=0, m=0, s=+1/2$
- **(B)** $n=2, l=1, m=0, s=-1/2$
- **(C)** $n=3, l=1, m=0, s=-1/2$
- **(D)** $n=2, l=2, m=1, s=+1/2$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(D) $n=2, l=2, m=1, s=+1/2$**

**Detailed Solution:**

The principal quantum number $n$ can take positive integer values $1, 2, 3, \dots$

The azimuthal quantum number $l$ can take integer values from $0$ to $n-1$.

The magnetic quantum number $m$ can take integer values from $-l$ to $+l$.

The spin quantum number $s$ can be $+1/2$ or $-1/2$.

In the set $n=2, l=2, m=1, s=+1/2$, the value of $l$ is equal to $n$. Since $l$ can only have values up to $n-1$, the maximum possible value of $l$ for $n=2$ is $1$.

Therefore, the set $n=2, l=2, m=1, s=+1/2$ is incorrect.

Answer: $n=2, l=2, m=1, s=+1/2$

</details>

### Q4. MHT CET 2026 (20 April Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

Identify pair of orbitals having similar $(n + l)$ values from the following.

**Options:**

- **(A)** 3s and 3p
- **(B)** 2p and 4s
- **(C)** 3d and 4p
- **(D)** 2p and 3p

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) 3d and 4p**

**Detailed Solution:**

The $(n + l)$ value for an orbital is calculated by adding the principal quantum number $n$ and the azimuthal quantum number $l$.

For $s$, $p$, $d$, and $f$ subshells, the values of $l$ are $0, 1, 2,$ and $3$ respectively.

Calculating $(n + l)$ for the given pairs:

For $3s$ and $3p$: $(3 + 0) = 3$ and $(3 + 1) = 4$

For $2p$ and $4s$: $(2 + 1) = 3$ and $(4 + 0) = 4$

For $3d$ and $4p$: $(3 + 2) = 5$ and $(4 + 1) = 5$

For $2p$ and $3p$: $(2 + 1) = 3$ and $(3 + 1) = 4$

The pair $3d$ and $4p$ has the same $(n + l)$ value of $5$.

Answer: 3d and 4p

</details>

### Q6. MHT CET 2025 (23 Apr Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

What is the number of node in 2 s orbital?

**Options:**

- **(A)** 0
- **(B)** 1
- **(C)** 2
- **(D)** 3

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(B) 1**

**Detailed Solution:**

The total number of nodes in an orbital is given by the formula $n - 1$.

For a 2s orbital, the principal quantum number $n = 2$ and the azimuthal quantum number $l = 0$.

Number of radial nodes = $n - l - 1 = 2 - 0 - 1 = 1$.

Number of angular nodes = $l = 0$.

Total number of nodes = $1 + 0 = 1$.

Answer: 1

</details>

### Q10. MHT CET 2024 (02 May Shift 2)

*Type:* `singleCorrect` | *Level:* `1`

Which of the following orbitals have same value of $(\mathrm{n}+l)$, as that of 3 d orbital?

**Options:**

- **(A)** 4 s
- **(B)** 3 s
- **(C)** 4 p
- **(D)** $\quad 2 p$

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Option:** **(C) 4 p**

**Detailed Solution:**

For $3d$ orbital, the principal quantum number $n = 3$ and azimuthal quantum number $l = 2$.

The value of $(n+l) = 3 + 2 = 5$.

For $3s$ orbital, $n = 3$, $l = 0 \Rightarrow (n+l) = 3 + 0 = 3$.

For $4p$ orbital, $n = 4$, $l = 1 \Rightarrow (n+l) = 4 + 1 = 5$.

For $2p$ orbital, $n = 2$, $l = 1 \Rightarrow (n+l) = 2 + 1 = 3$.

The $4p$ orbital has the same value of $(n+l)$ as the $3d$ orbital.

Answer: 4 p

</details>
