### Q4. NTA Abhyas (JEE Main) 2020

*Type:* `numerical` | *Level:* `1`

If number of aldose, ketose, furanose and pyranose units present in maltose are p, q, r, s respectively. Find the value of <math xmlns="http://www.w3.org/1998/Math/MathML"><mi mathvariant="normal">p</mi><mo>+</mo><mi mathvariant="normal">q</mi><mo>+</mo><mi mathvariant="normal">r</mi><mo>+</mo><mi mathvariant="normal">s</mi></math>

<img src="https://cdn-question-pool.getmarks.app/nta_abhyas/jee_main/images/a8814cfc-1094-4da9-8cdf-f99f03c31a62.jpeg" style="max-width:100%; object-fit:contain" style="width:3.525in;height:1.75833in" />

<details>
<summary><b>View Answer & Solution</b></summary>

**Correct Value:** **4**

**Detailed Solution:**

Monomer of maltose is <math><mi mathvariant="normal">α</mi></math> -D-glucopyranose. It is disaciharide, so 2 aldose and 2 pyranose forms are present in maltose.
Hence, p = 2, q = 0, r = 0 and s = 2
So, sum of p + q + r + s = 2 + 0 + 0 + 2 = 4.
